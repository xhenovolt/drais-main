# DRAIS — Export & Print Terminology Glossary

Scoped to **everything that leaves the browser**: server-rendered PDFs,
printed report cards, certificates, ID cards, transcripts, Excel exports
of grade books, audit-log CSVs.

These strings get the highest scrutiny because:

1. They appear on paper that parents read and government inspectors review.
2. They cannot be hot-fixed after issuance — a typo in a printed
   certificate means reprinting.
3. They mix with school-typed dynamic content (motto, headteacher
   signature line) which is **never translated**.

## 11. Bidirectionality + mirroring rules for exports

The server-rendered PDF must respect RTL when the document locale is
Arabic. Key rules baked into the export glossary:

- **Text direction**: `dir="rtl"` at the document level when `locale=ar`.
- **Table column order**: in RTL, the first column (Subject) sits on the
  right; numeric columns (Score, Total) on the left.
- **Page numbering**: still "Page 1 of 5" but rendered as "صفحة ١ من ٥".
- **Date format**: prefer "١٥ مايو ٢٠٢٦" in narrative blocks, "٢٠٢٦/٠٥/١٥"
  in compact table cells.
- **Numerals**: Eastern Arabic numerals (٠–٩) inside Arabic narrative
  blocks; Latin numerals (0–9) inside cells whose values cross-reference
  data the school still maintains in English (e.g. UCE letter grades
  D1, C5, F9).
- **School logo + photo**: not mirrored; absolute-positioned images keep
  their original orientation.
- **Signature lines**: drawn right-to-left in Arabic mode; the printed
  name is right-aligned.

These rules belong to the renderer, not the dictionary, but the
**phrasing** above was chosen with them in mind (no English-style
abbreviations like "No." which break in RTL; instead "رقم").
