# DRAIS v1.87.0 — Attendance Pattern Analytics

## Attendance Intelligence Program · Phase 6

DRAIS now learns attendance *behaviour* over time and raises deterministic, explainable alerts when it changes.

## Release notes
- **Attendance Trends** — new page /attendance/trends (sidebar): a stacked daily present/late/absent chart, a first-half-vs-second-half trend headline (improving / declining / stable), and **intelligent alerts**:
  - attendance decline (present rate trending down)
  - unusual mass absence today (vs the school's own recent norm, 2σ)
  - lateness spike today / creeping lateness
  - per-class (learners) and per-department (staff) drift below the school average
- Learners/Staff toggle + 14/30/60/90-day window. Charts use the DRAIS status palette (present/late/absent), colour always paired with labeled axes + legend.

## Architecture
- `src/lib/attendance/pattern-analytics.ts` — **pure** detectors (`trend`, `analyzeSeries`, `analyzeGroups`, 14 unit tests) over engine verdicts; no ML, just explainable statistics. `/api/attendance/patterns` builds the series/groups and composes them. Nothing written.
