# v1.133.0 — Platform BI: see the business (Phase 24)

**Nature:** minor (E-21). The capstone of the money wave — the founder can now
see the *business*, not just the operations.

## What this adds

A **Business** view in the Control Center (`/control/bi`), built on the billing
ledger + plan catalog:

- **MRR / ARR** — each active school's plan normalised to a monthly-equivalent
  figure (annual → /12, termly → prorated, monthly → itself, one-time → excluded),
  summed across active schools; ARR = MRR × 12.
- **Revenue collected** — last 30 days + all-time, from recorded payments.
- **Outstanding** — unpaid invoice balance across the platform.
- **School mix** — active / suspended / archived.
- **Churn (30d)** — schools newly suspended in the last month.
- **Plan mix** — active schools per plan, with share bars. Exportable to CSV.

## Code + tests

- `src/lib/control/platform-bi.ts` — `getPlatformBI()` + the **pure**
  `monthlyEquivalent` (4 unit tests). Reuses the plan catalog's cycle maths.
- `GET /api/control-center/bi` (audited `viewed_bi`).
- `/control/bi` page + **Business** nav entry.

The numbers populate as you assign plans and record payments (the ledger from
Phases 11–12 / v1.123–v1.124). No new cron; no schema change.
