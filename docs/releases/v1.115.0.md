# v1.115.0 — Export & print across the Control Center

**Nature:** minor (data can now leave the system).

Addresses the feedback: *"the control routes have no export buttons for printing
what is in the system."*

## What you can export now

Every control list has **CSV** + **Print** buttons:

- **Schools** — name, status, learners, staff, devices online/total, plan, sub
  status, district, country, last sync.
- **Devices** — serial, name, school, status, online, model, firmware, IP, users,
  location, last seen.
- **Plans** — code, name, tier, active, assigned schools, every limit, features.
- **Platform health** — each school needing attention + its issues.
- **Audit log** — when / who / action / resource / detail / IP.

CSV downloads are **Excel-friendly** (UTF-8 BOM, RFC-4180 quoting) and reflect
the current filters (e.g. a device search or a school "show deleted" toggle).

## Print

A **Print** button on each list, plus a print stylesheet that drops the dark
chrome to a clean white sheet (hides the nav/header, forces legible black-on-white)
so a printed or PDF'd page is actually readable — the dark theme no longer prints
as a black rectangle.

## Code + tests

- `src/lib/control/export.ts` — **pure** `toCSV` (5 unit tests: inference,
  explicit columns + value fns, comma/quote/newline escaping, empty rows,
  null handling) + `downloadCSV`.
- `src/app/control/_components/ExportButtons.tsx` — reusable CSV + Print control
  (`no-print` so it never appears in the output).
- Wired into Schools, Devices, Plans, System Health, Audit.
