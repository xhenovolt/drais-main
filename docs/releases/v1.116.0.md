## Four themes

A theme control sits in the Control Center header (click to cycle); the choice is
remembered per operator in `localStorage`:

- **System** — follows the OS light/dark preference.
- **Light** — clean white sheets, dark text.
- **Dark** — the original console look (default).
- **High-contrast** — pure black/white with bright accents, for accessibility.

## How it works

Rather than rewrite every page's colour classes, a scoped theme layer on the
control root (`data-theme`) remaps the slate palette:

- `light` / `system` (under `prefers-color-scheme: light`) → slate backgrounds
  become white/grey, slate text becomes dark.
- `contrast` → black backgrounds, white text and borders, brightened indigo
  accents.
- `dark` → the classes as authored (no overrides).

Every existing page inherits the theme automatically — no per-page changes — and
the print stylesheet from v1.115.0 still forces a clean white sheet regardless of
the active theme.
