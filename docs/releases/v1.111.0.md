# v1.111.0 — Plans: full CRUD + Control dashboard NaN fix

**Nature:** minor (the plan catalog becomes fully editable) + a bug fix.

Addresses direct operator feedback that the Control Center was read-mostly.

## Plans are now fully manageable

`/control/plans` is a real editor, not a viewer:

- **Create** a brand-new plan ("New plan") — code, name, tier, limits, features.
- **Edit everything** — name, tier, every limit, active state (not just limits).
- **Features / modules** — toggle each module from the catalog on/off per plan
  (checkbox grid), so a plan explicitly declares what it includes.
- **Activate / deactivate** — a plan can be retired without deleting it.
- **Duplicate** — clone a plan as a starting point (`…_copy`).
- **Delete** — removes a plan, **refused (409) while any school is still
  assigned** to it, with the assigned-school count shown on every card.

Every write is audited (`plan_saved` / `plan_deleted`).

## API

- `GET /api/control-center/plans` now returns each plan's **assigned-school
  count** and the **module catalog** (for the feature picker).
- `DELETE /api/control-center/plans?code=…` (super-admin; blocks in-use plans).
- `POST` upsert already handled create/update — now driven fully from the UI.
- Lib: `deletePlan` (guarded) + `schoolsOnPlan` in `control/subscriptions.ts`.

## Bug fix — Control dashboard "NaN"

The **Devices Online** card showed `NaN`: the tile did
`Number("5/10").toLocaleString()` on an already-formatted `online/total` string.
Tiles now render numbers with `toLocaleString()` and pass strings through
untouched.

## Next (from the same feedback)

Per the agreed order: Schools lifecycle (archive/delete/restore), **opt-out**
module visibility (every school keeps all modules unless explicitly disabled —
then it truly hides), full device detail + richer cards, exports/print across
control routes, and light/system/high-contrast theming.
