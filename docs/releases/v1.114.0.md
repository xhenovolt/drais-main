# v1.114.0 — Control device detail + richer cards

**Nature:** minor (the device surface stops hiding information).

Addresses the feedback that Control showed devices but *"a lot of information
about the device is heavily hidden."*

## Richer inventory cards

Each device card on `/control/devices` now shows a second meta line inline:
firmware version · IP (or LAN IP) · user count · push version · registration
date — alongside the existing name / model / location / owner / status / online.

## Full device detail drawer

Opening a device (the history button) now shows its **complete detail**, not
just the ownership timeline:

- **Live counts** — today's punches, enrolled users, pending device commands.
- **Full attribute grid** — name, school, status, online, model, type, firmware,
  push version, IP, LAN IP, location, registered-at, last-seen, last-activity,
  and last-punch time.
- **Ownership timeline** below it (assign / release / acquire / retire, with
  school names + impact counts).

## API / code

- `deviceDetail(sn)` in `control/devices.ts` — the device row + owner + live
  counts (today punches, pending commands, mapped users) + last-punch time.
- `GET /api/control-center/devices/[sn]` now returns `{ device, timeline }`
  (was timeline-only).
- `listPlatformDevices` returns the extra columns the cards need (device_type,
  last_activity, ip_address, lan_ip, device_user_count, created_at).
