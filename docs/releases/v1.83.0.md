# DRAIS v1.83.0 — About / System Information (institutional memory)

## Release notes
- New **/about** page (Settings → About DRAIS): product identity, current release card (version/date/type/status), categorized changes, full release history (300 releases recovered from git, grouped by series, expandable), and safe system information with a live System Health link.
- **Changelog architecture**: `src/data/changelog.json` generated by `scripts/update-changelog.mjs` — conventional commits map to NEW/IMPROVED/FIXED/SECURITY/PERFORMANCE; release type derived from the semver delta. No release text lives in components.
- **Automatic workflow**: the pre-commit hook (after version bump) records every commit's release entry; runs missed are self-healed from `git log` on the next run.

## Database changes
None.

## Security
Client bundle exposes only changelog + version — package.json (dependency list), env details and infrastructure are never shipped.

## Rollback
`git revert`; the JSON file and script are inert without the page.
