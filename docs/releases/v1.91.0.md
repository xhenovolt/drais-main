# DRAIS v1.91.0 — Person Attendance Intelligence (+ daily absence finalization)

Answers the question "does DRAIS understand that such-and-such a teacher is often absent?" — now: yes.

## The two-part fix
Individual understanding was impossible before because **absence wasn't being recorded**: evaluateDay only wrote a verdict for people who punched, so no-shows produced no row. Over 30 days JIPRA had 2 absent rows for 155 staff. So:

### 1. Daily absence finalization
`finalize-day.ts` — for a school-local date, runs evaluateDay for every EXPECTED person (active staff / actively-enrolled learners) who has no verdict yet, materialising the absent rows the engine would have produced. Idempotent, guarded (never a future date; today only after ~17:00; skips holidays). Wired into the intelligence sweep (today after hours + yesterday), so it runs automatically without anyone opening a page.

### 2. Person Attendance Intelligence
`person-intelligence.ts` — pure `profilePerson()` reads a person's daily verdict series and returns rates, absence streaks, and a **first-half-vs-second self-comparison**, classifying each individual: reliable / occasionally-late / chronically-late / **frequently-absent** / **declining (unusual for them)** / improving. Not a leaderboard — an understanding of the person's own pattern.

## Visible deliverable
**Attendance Profiles** — new page /attendance/profiles (sidebar): a **watch-list** of people who need attention (frequently absent, declining, chronically late) with a plain sentence each ("Absent 30% of tracked days, currently on a 3-day streak — well above normal"; "Absence rose from 5% to 25% recently — a change from their own pattern. Worth a conversation."), summary counts, staff/learner toggle, and every person's behavioural label on demand.

## Database changes
None (new absent rows use the existing attendance_records schema).

## Tests
223 pass (9 person-intelligence + existing). Build clean.

## Rollback
`git revert`; finalization only writes standard verdict rows the engine already produces.
