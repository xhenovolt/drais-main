# DRAIS v1.93.0 — Attendance dashboard fix + Intelligence everywhere

## The bug
The attendance dashboard (/attendance) showed "failed to load" for everyone: its hourly-chart query repeated a parameterised `HOUR(DATE_ADD(punch_at, ...))` expression in both SELECT and GROUP BY, which TiDB's only_full_group_by mode rejects — one failing query 500'd the whole endpoint. Fixed by grouping on the SELECT alias. Dashboard loads again.

## Intelligence, surfaced
DRAIS is infrastructure, not a logbook — so the intelligence layers now appear where people look:
- New **Attendance Intelligence strip** (reusable component) on BOTH /attendance and the main /dashboard: six live tiles — Health score, Behaviour watch-list (+ roster-review count), Attendance gaps, Clock integrity, Identity health (duplicates/unknowns), Device fleet reputation — each linking straight to its full feature, plus quick links to Trends, Event Explorer and Founder Independence.
- Backed by one best-effort roll-up endpoint (/api/attendance/intelligence-summary); any slow layer degrades to a dash, never breaks the dashboard.

So from the front door an administrator sees, at a glance: is attendance healthy, who needs watching, is anything broken — and can click into detecting-behaviour, recovery, device health, etc.
