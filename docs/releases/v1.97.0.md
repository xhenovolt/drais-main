# DRAIS v1.97.0 — Identity correction: preview + undo (Founder-Independence Phase A)

First phase of the attendance founder-independence plan (docs/audits/ATTENDANCE_FOUNDER_INDEPENDENCE_AUDIT.md), closing gap FD-1: identity correction was irreversible in the UI, so a mis-map needed the founder.

## What shipped
- **Preview before apply.** When you pick the correct person in the Correct modal, DRAIS now shows the exact impact first: "This moves N attendance events (date → date) from A → B. Verdicts for both re-evaluate. Reversible with Undo last." No more correcting blind.
- **Undo last correction.** An "Undo last" button reverts the most recent correction on a PIN back to its previous owner — using the recorded biometric_mapping_history binding, re-attributing the events back and re-evaluating both people's verdicts. Guarded against double-undo; the undo itself is audited.

Both make every correction safe and reversible by a normal administrator — no SQL, no founder.

## API
- `POST /api/attendance/identity-correction` gains `action:'preview'` and `action:'undo_correction'`.

## Database changes
None (reuses biometric_mapping_history + attendance_raw_events).

## Tests
48 biometric tests pass (3 new for reversal/no-op guards). Build clean.

## Rollback
`git revert`; preview is read-only and undo only reverts to an already-recorded prior binding.
