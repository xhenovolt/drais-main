# DRAIS v1.96.0 — Control Center: enter any school (secure impersonation)

Turns the Control Plane into a true operating subsystem: an Xhenvolt super-admin can enter ANY school and use its entire app — every route, module and data view — without the school's password. The standard "operate as customer" capability of mature SaaS, built with strong safety rails.

## What shipped
- **"Open school"** button on each school's Control Center detail page → mints a real, short-lived (2h) school session bound to that school and drops you into the normal school app at /dashboard. All routes/modules/data work because it's a genuine (impersonated) session.
- **Full access**: the impersonation session is elevated to super-admin (justified — a *verified* Xhenvolt super-admin started it), so nothing in the school is walled off even if that school's own users lack admin roles.
- **Persistent amber banner** across the whole school app while impersonating: "Xhenvolt Control — operating inside [School] as [user] … Exit to Control" — impossible to forget you're on live school data. One-click Exit ends the session and returns to /control.
- **Fully audited**: `impersonation_started` / `impersonation_ended` in control_audit_logs (which control user, which school, operating-as user, when, IP); the session row carries `impersonated_by_control_user` so every action taken inside is traceable to the Xhenvolt operator.

## Security architecture
- Start requires the isolated control super-admin (drais_control + canManage). School login and existing school sessions are untouched; the drais_control cookie is preserved so Exit is clean.
- The elevation applies ONLY to sessions carrying `impersonated_by_control_user`, which only the control super-admin API can set.
- Session query safety: the new column is guaranteed by a promise-gated runtime ensure BEFORE the hot session query references it, so a fresh deploy can never break logins.

## Database changes
One additive nullable column: `sessions.impersonated_by_control_user` (created at runtime by the app, not by hand).

## Tests
Control suite passes; build clean.

## Rollback
`git revert`; the column is nullable/unreferenced after revert.
