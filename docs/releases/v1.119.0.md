# v1.119.0 — Console security Phase 8: login brute-force guard + bootstrap secret

**Nature:** minor (security hardening of the platform console — E-1, E-5).
First increment of the Security wave.

## E-1 · Login rate-limiting + lockout

The one credential that governs every tenant was brute-forceable at full speed.
Now failed logins are tracked and throttled:

- Failures per account are counted in a 15-minute window
  (`control_login_attempts`).
- After **5** failures the account locks with **exponential backoff** —
  30s → 60s → 120s → … capped at **15 min** — measured from the last failure, so
  the wait shrinks as time passes.
- A locked attempt returns **HTTP 429** with a `Retry-After` header and a
  countdown message; a good login **clears** the counter.
- Every lockout is audited (`login_throttled`).

The decision logic (`throttleDecision`) is **pure and unit-tested** (6 tests:
threshold, backoff curve, cap, cooldown decay, custom options). Login stays
constant-shape (dummy verify on unknown email) so it doesn't leak which accounts
exist.

## E-5 · Bootstrap secret

First-run setup ("whoever reaches a fresh deployment first becomes the founder")
is now gated: if **`CONTROL_BOOTSTRAP_SECRET`** is set in the environment, the
first operator can only be created by someone who supplies it. The setup screen
shows a **Bootstrap secret** field when required. If the env var is unset,
behaviour is unchanged (backward-compatible).

## Migration / ops notes

- `control_login_attempts` is created via runtime schema-ensure (additive) — no
  manual migration.
- To enable the bootstrap gate on a fresh deployment, set
  `CONTROL_BOOTSTRAP_SECRET` before first setup. Existing deployments (already
  past setup) are unaffected.
- **No new cron** — this change adds none.

## Files

- `src/lib/control/login-guard.ts` — pure `throttleDecision` + attempt
  tracking (`recentFailures` / `recordLoginAttempt` / `clearFailures`).
- `loginControl` wired to the guard; auth route returns 429 + exposes
  `bootstrap_secret_required`; setup UI adds the secret field.
