# DRAIS v1.92.0 — Self-scaling Person Intelligence (no scripts, no founder)

Makes v1.91's per-person understanding run ITSELF, for every school, forever — the founder-independence principle applied to the feature itself.

## What changed
Everything that was done manually last release (backfill absences, clean pollution, decide who's roster-bloat vs real absentee) is now built-in and automatic:

### 1. DRAIS separates roster noise from behaviour itself
`profilePerson()` now classifies a person with ≥5 tracked days who NEVER once showed up as **never_present → roster review**, not "frequently absent". The behavioural watch-list is therefore automatically clean of former/unenrolled people — no human decides what's roster bloat. Live on JIPRA: 47 never-present people auto-separated into roster review, leaving a real watch-list (e.g. "MBONYOBYAYO PETER — chronically late 71%", "KARIM KITOORO — declining, unusual for them 0%→25%").

### 2. Self-healing finalization
The intelligence sweep now catches up the **last 7 school-local days** (each outage-guarded so pre-deployment / device-down days are skipped, never mass-marked absent), not just today. A multi-day gap repairs itself with zero manual backfill. Idempotent — steady-state is cheap (only new no-shows are processed).

### 3. Roster review surfaced in the product
/attendance/profiles now shows a "Roster review" section (never-present people to mark inactive / fix enrollment) DISTINCT from the behavioural watch-list — so the admin, not the AI, acts on roster hygiene.
