# DRAIS v1.100.0 — Guided Person Merge (Founder-Independence Phase B)

Closes gap FD-2: duplicate person records (the same human entered twice — "MULEMA PAUL" ×2) split attendance and corrupt analytics, and consolidating them required scripts. Now it's a safe, previewable, audited admin workflow — no founder.

## What shipped (on /attendance/identity-intelligence)
- **Duplicate people** section: DRAIS detects same-name person records (case/space/punctuation-insensitive), showing each copy's attendance weight (events, PINs).
- **Pick keeper → preview → merge**: choose the record to keep (defaults to the one with the most enrollments/attendance), preview exactly what moves ("Merges 2 records: 19 events, 23 verdicts move in"), then merge. All attendance from the duplicates moves into the keeper via the existing person-reattribution engine (events preserved, verdicts rebuilt), and the duplicate records are **soft-deleted to Trash** (restorable). Fully audited.

## Architecture
- `src/lib/biometric/person-merge.ts` — **pure** `normalizeName()` + `groupDuplicates()` (8 tests) + `findDuplicatePeople` / `previewMerge` / `mergePeople` (built on reattributePerson).
- `/api/attendance/person-merge` (GET groups; POST preview/merge). Keeper must be a real staff/learner; losers soft-deleted, never hard-deleted.

## Database changes
None (reuses reattribution + soft-delete).

## Tests
56 biometric tests pass (8 new). Build clean.

## Rollback
`git revert`; merged-in duplicates are soft-deleted (restorable from Trash) and every move is audited.
