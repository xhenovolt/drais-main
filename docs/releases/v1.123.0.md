# v1.123.0 — Money wave Phase 11: billing ledger (invoices + payments)

**Nature:** minor (E-6). First increment of the Money wave — turns declarative
pricing into transactional truth.

## The gap this closes

Plans had prices and the platform could time-suspend, but it couldn't answer
"who owes what, who paid, what's outstanding" — there was no ledger. Now there is.

## Invoices, payments, reconciliation

- **Generate invoice** — creates one billing cycle for a school's plan. The
  period starts from the later of today or the current paid-through date (so
  invoices stack cleanly), runs one cycle (annual/termly/monthly), and carries
  the plan's price + currency + due date.
- **Record payment** — log a payment (amount, method, reference) against an
  invoice. Partial payments accumulate.
- **Reconciliation** — when an invoice is **paid in full**, it's marked paid and
  the school's `subscription_end_date` is **extended to the invoice's period
  end**. So **payment drives access**: the existing session gate then
  auto-suspends a school whose paid-through date has passed, and a recorded
  payment lifts it — no manual date-picking.
- **Void** an unpaid invoice (payment history is preserved).

## Surfaces

- Each school's operations view gains a **Billing** panel: total outstanding,
  Generate-invoice, and per-invoice status (paid / issued / overdue / void),
  amount, period, outstanding, with **Pay** + **Void** actions.
- `GET/POST /api/control-center/schools/[id]/billing`
  (generate_invoice / record_payment / void_invoice).
- New RBAC permission **`billing.manage`** (operator+ and super-admin); reads
  stay open to any control session.

## Code + tests

- `src/lib/control/billing.ts` — schema (`platform_invoices` / `platform_payments`),
  `generateInvoice` / `recordPayment` (reconciles) / `voidInvoice` / `schoolBilling`,
  and **pure** `outstanding` / `deriveInvoiceStatus` / `computePeriod` (8 tests).
- Every mutation audited (`invoice_generated` / `payment_recorded` /
  `invoice_voided`).

No new cron; additive runtime schema.
