# DRAIS v1.95.0 — Control Center: operate schools without their credentials

Continues the DRAIS Control Plane (v1.84.0) with the capability that most advances founder independence: managing a school's lifecycle and subscription from the Xhenvolt console, without ever logging into the school.

## What shipped
On each school's Control Center detail page (super-admin only), a **Subscription & lifecycle** panel:
- **Suspend / Reactivate** a school — suspension is already enforced at the auth layer (the middleware blocks suspended schools on every protected request), so this has real teeth. Suspending blocks operation without touching data.
- **Subscription management** — set plan (Trial/Bronze/Silver/Gold/Enterprise), status (trial/active/past_due/cancelled) and end date.
- **Quick extend** — +30 / +90 / +365 days on the subscription end date (one click).

Every action is recorded in the Control Center audit log (`control_audit_logs`) with who / when / old → new / reason — new actions: `school_suspended`, `school_activated`, `subscription_updated`, `subscription_extended`.

## Security
Isolated Xhenvolt domain (unchanged): `canManage` (XHENVOLT_SUPER_ADMIN) required; school auth untouched. All writes scoped to `schools` by id and audited.

## Database changes
None — writes existing `schools` columns (status, subscription_plan, subscription_status, subscription_end_date).

## Tests
Control auth suite passes; build clean.

## Rollback
`git revert`; additive POST actions only.
